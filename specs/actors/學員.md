# 學員

## 描述
購買或被授權課程的 WordPress 用戶，在前台教室觀看章節、標記完成進度、發表留言。

## 關鍵屬性
- WordPress 角色：任何已登入用戶（不限角色）
- 操作範圍：僅限自己已被授權的課程
- 認證方式：WordPress 登入 Cookie
- 權限判斷：`user_meta` 中 `avl_course_ids` 包含目標課程 ID，且未到期

## 作業（Issue #131）

| 能力 | 對應規格 |
|------|---------|
| 查看章節作業、課程作業總覽、單一作業，以及自己的繳交與評語 | `features/assignment/查詢學員作業.feature` |
| 上傳附件（只需登入） | `features/assignment/上傳作業附件.feature` |
| 繳交 / 重交作業（重交覆寫、評語清空、狀態回到待批改；介面在已通過時隱藏重交按鈕） | `features/assignment/繳交作業.feature` |
| 下載自己上傳的附件 | `features/assignment/下載作業附件.feature` |
| 在自己繳交的討論串與老師往返（第二波） | `features/assignment/查詢作業討論串.feature`、`發送作業討論訊息.feature` |
| 收到批改結果通知信、截止前提醒信（站長需建立對應郵件模板） | `features/assignment/批改作業.feature`、`作業截止提醒.feature` |

- 查看作業與繳交的前置閘門：`CourseUtils::is_avl`（含課程權限包）且未到期、課程已開課；否則回應「尚未報名此課程」
- 作業不阻擋章節完成；批改通過時系統自動把作業所屬章節標為完成
- 課程啟用線性觀看時，不可繳交鎖定章節的作業（沿用 LinearViewing 解鎖邏輯）
- 被移出課程或到期後無法查看 / 繳交作業，但繳交紀錄保留，自己的討論串仍可讀寫（同參考實作）
