# 管理員

## 描述
WordPress 後台操作者，負責建立課程、管理章節、設定外掛、管理學員與講師。擁有 `manage_options` 或 `edit_products` 能力（Capability）。

## 關鍵屬性
- WordPress 角色：`administrator` 或具有 `edit_products` 能力的自訂角色
- 操作範圍：所有課程、所有學員、全站設定
- 認證方式：WordPress 登入 Cookie + `X-WP-Nonce` Header

## 作業與批改（Issue #131）

管理員是作業功能中**唯一**的出題者與批改者（業務依據 zenbu-site-2.0：admin / editor 可批改，講師角色不可）。

| 能力 | 對應規格 |
|------|---------|
| 在章節下建立 / 更新 / 刪除（移至垃圾桶）/ 排序作業，查詢章節或課程的作業 | `features/assignment/建立作業.feature`、`更新作業.feature`、`刪除作業.feature`、`排序作業.feature`、`查詢章節作業列表.feature` |
| 跨課程查看繳交列表、批改統計、有繳交紀錄的課程、學員背景資料 | `features/assignment/查詢作業繳交列表.feature`、`查詢作業批改統計.feature`、`查詢有繳交紀錄的課程.feature`、`查詢作業學員背景資料.feature` |
| 批改為通過 / 未通過 / 改回待批改並撰寫評語，可隨時改判 | `features/assignment/批改作業.feature` |
| 下載出現在學員繳交中的附件 | `features/assignment/下載作業附件.feature` |
| 以老師身分在繳交討論串往返（第二波） | `features/assignment/查詢作業討論串.feature`、`發送作業討論訊息.feature` |
| 匯出單一作業繳交 CSV、匯出批改用 CSV（第一波）；匯入批改結果 CSV（第二波） | `features/assignment/匯出單一作業繳交CSV.feature`、`匯出批改用CSV.feature`、`匯入批改結果CSV.feature` |

- 權限判定：REST `permission_callback` 沿用 ApiBase 預設 `manage_options || manage_woocommerce`
- 管理員不繳交作業；教室預覽時以管理員端作業列表呈現，繳交表單停用
- 批改會寫入 `graded_by`（最後一次批改的管理員）與 `graded_at`
