# 講師

## 描述
被指派到課程的教學者，具有讀取課程資料的權限。透過課程的 `teacher_ids` 多筆 meta 記錄關聯。

## 關鍵屬性
- WordPress 角色：任何已登入用戶（由管理員指派）
- 操作範圍：被指派的課程資料（唯讀）
- 儲存方式：課程商品的 `teacher_ids` postmeta（多筆 rows，每筆一個 user ID）

## 作業與批改（Issue #131）

- **講師不具作業管理與批改權限**。講師（`is_teacher = yes` + 課程 `teacher_ids`）在 Power Course 是課程展示與留言通知用的資料標籤，沒有後台 REST 權限；業務依據 zenbu-site-2.0 的 instructor 角色同樣不可批改。
- 「老師要有一個畫面管理全部課程的作業」對應為**管理員**使用的跨課程批改頁（`specs/ui/作業批改頁.md`）；討論串中管理員以「老師」身分（sender_type = teacher）發言。
- 若日後要讓講師批改自己被指派課程的作業，需新增 capability 與 `teacher_ids` 範圍過濾，屬新需求。
