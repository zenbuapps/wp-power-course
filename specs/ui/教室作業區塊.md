# 教室作業區塊

## 描述
學員在前台教室（PHP 模板 + vanilla TS，`inc/templates` / `inc/assets`）看到的作業區塊；
介面行為以 zenbu-site-2.0 `AssignmentsSection.tsx` 與 `assignments/CourseAssignmentsOverview.tsx` 為準。
出現在章節內容下方（該章節的作業），另提供課程作業總覽。

## 關鍵元素
- 作業卡片（`features/assignment/查詢學員作業.feature`）：
  - 標題、作業說明、截止時間；未繳交且已超過截止時間時以警示色加上「已逾期」（仍可繳交，前端計算）
  - 狀態徽章：未繳交 / 待批改 / 通過 / 未通過
  - 評語
- 繳交表單（`features/assignment/繳交作業.feature`）：
  - 文字輸入框（允許文字時顯示；必填時標示）
  - 附件上傳（允許檔案時顯示；顯示上限數量；上傳後只顯示檔名，點擊經驗權下載，`features/assignment/上傳作業附件.feature`、`下載作業附件.feature`）
  - 按鈕文案：未繳交為「繳交」，已繳交為「重新繳交」；狀態為通過時隱藏重新繳交
- 討論串（第二波，`features/assignment/查詢作業討論串.feature`、`發送作業討論訊息.feature`）：
  - 只有「已有繳交」的卡片才有「與老師討論」切換鈕；尚未繳交時整塊隱藏，頁內首次繳交成功後不重新整理就會出現。狀態為通過時繳交表單隱藏，討論串照常顯示
  - **展開才載入**：展開 = 讀取 = 後端把老師發送的未讀訊息標為已讀；收合後再展開會重新讀取
  - 訊息顯示「我 / 老師」、時間（站台時區，到分鐘）；自己的訊息被老師讀過時顯示「已讀」。單行輸入、Enter 送出（Shift+Enter 與輸入法選字中的 Enter 不送出）
  - **送出前 trim，純空白不送**（UI 行為，與參考實作 `AssignmentReviewView.tsx` 一致；後端 API 不 trim、純空白合法，見 `發送作業討論訊息.feature`）
  - 訊息本文以純文字呈現（`textContent`，訊息節點來自 PHP 輸出的 `<template>`），不解析 HTML
  - 不受線性觀看鎖定影響（只擋繳交，不擋討論串，D29）；管理員預覽模式不輸出討論串
  - 學員端沒有未讀提示：新的老師回覆要展開才看得到（參考實作有未讀徽章，PC 本波不做，用戶裁決 UC-W2-3，建議另開 issue）
- 線性觀看：課程啟用線性觀看時，鎖定章節的作業不可繳交（表單停用並顯示「此章節尚未解鎖，請先完成前面的章節」；鎖定判定沿用 LinearViewing）
- 管理員預覽模式：改用管理員端作業列表（`features/assignment/查詢章節作業列表.feature`），表單與按鈕全部停用
- 課程作業總覽：作業總數、已通過數、通過百分比（前端依回傳資料計算），依章節順序列出每份作業與狀態
