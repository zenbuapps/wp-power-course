# 作業批改頁

## 描述
管理員後台（React SPA）跨課程管理所有學員作業繳交的頁面，對應 Issue #131「老師要有一個畫面管理全部課程的作業」；介面行為以 zenbu-site-2.0 `apps/web/app/zb-course/submissions/SubmissionsManager.tsx` 為準。
路由建議：`js/src/pages/admin/Assignments/`（與 AccessPasses、Students 同層的獨立選單）。

## 關鍵元素
- 課程分頁（Tab）：全部 + 有繳交紀錄的課程與繳交數（`features/assignment/查詢有繳交紀錄的課程.feature`）
- 統計卡：全部 / 待批改 / 通過 / 未通過 / 通過率 / 平均批改時間，隨課程分頁切換範圍（`features/assignment/查詢作業批改統計.feature`）
- 狀態篩選：全部 / 待批改 / 通過 / 未通過；列表依繳交時間由新到舊，分頁每頁最多 200 筆（`features/assignment/查詢作業繳交列表.feature`）
  - **預設為「待批改」**（對齊參考實作 `SubmissionsManager.tsx:513`；commit `ebeda1b9`）。這不只是畫面偏好：「匯出批改用 CSV」沿用目前篩選，預設「待批改」時整份匯出再匯回不會碰到已批改（通過 / 未通過）的學員，不會讓他們再收到一封批改通知；預設若是「全部」，老師匯出 → 填寫 → 匯回，已批改學員會被重新批改並再收到通知（匯入的每一列都是一次完整批改，沒改動的待批改列仍會被寫入批改時間，見匯入段落）。API 本身的預設（未帶 status）仍是全部，只有這個頁面的初始篩選是「待批改」
  - 「待批改」為 0 筆時，「匯出單一作業 CSV」的作業選單為空（選項取自目前列表出現過的作業），切到「全部」即可
- 列表欄位：學員姓名與 Email、課程、作業、繳交時間、批改狀態、附件（依附件大類顯示圖示）、討論未讀徽章
- 詳情區：
  - 學員文字內容與附件（點擊經驗權下載端點取得檔案，`features/assignment/下載作業附件.feature`）
  - 批改操作：通過 / 未通過 / 改回待批改 + 評語；顯示最後批改時間（`features/assignment/批改作業.feature`）
  - 學生背景資料：基本資料、本課程作業統計、學習進度（`features/assignment/查詢作業學員背景資料.feature`）
  - 討論串（第二波，`features/assignment/查詢作業討論串.feature`、`發送作業討論訊息.feature`），放在詳情區最後一段：
    - 抽屜開啟即載入；載入 = 後端把學員的未讀訊息標為已讀，載入成功後列表的「討論」徽章歸零。換一筆繳交就重新載入；不輪詢、不做未讀優先排序
    - 訊息顯示「老師 / 學員」、時間（站台時區，到分鐘）；老師一方的訊息被學員讀過時顯示「已讀」。發送者一律顯示「老師」，多位管理員之間分不出是哪一位（`mine` 依端別，不看 sender_id）
    - 單行輸入、Enter 送出（輸入法選字中的 Enter 只確認選字，不送出）；**送出前 trim，純空白不送**（UI 行為，與參考實作 `TeacherThread` 一致；後端 API 不 trim、純空白合法，見 `發送作業討論訊息.feature`）；送出成功的訊息就地附加，不為了顯示自己的訊息再打一次會標已讀的 GET
    - 訊息本文一律以純文字呈現（React 文字節點），不解析 HTML；發訊息不寄信、不寫日誌
- 工具列：匯出單一作業 CSV、匯出批改用 CSV（第一波）；匯入批改 CSV（第二波，`features/assignment/匯入批改結果CSV.feature`）
  - 匯入：選好 CSV 檔後直接上傳（單檔 ≤ 10MB、資料列 ≤ 5000）；結果以頁內可關閉的 Alert 顯示「共 N 筆・更新 X・略過 Y・失敗 Z」與錯誤列（前 20 筆，其餘以「另有 N 筆錯誤」帶過；列號 0 代表整份檔案無法處理，只顯示訊息），不用 toast，讓管理員對照 CSV 修正
  - 匯入成功後重新取得列表、統計與課程分頁，狀態篩選維持不動：預設「待批改」下，被改成通過 / 未通過的列會離開目前列表，屬預期行為
  - 大檔匯入的請求逾時為 10 分鐘（axios 預設 30 秒不夠；前端先逾時但後端照樣套完並寄信，老師會誤以為失敗而重匯）。主機閘道（約 60～100 秒）仍可能截斷，依用戶裁決 UC-W2-2 = A 不防重匯、不加提醒文字：整份重匯會讓已批改學員再收一次批改通知（詳見 `.claude/rules/wordpress.rule.md` Assignment Resource）
