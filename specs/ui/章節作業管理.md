# 章節作業管理

## 描述
管理員在課程編輯頁的章節編輯區管理該章節作業的介面（React SPA，位於 `js/src/pages/admin/Courses/Edit` 的章節編輯流程內）；
介面行為以 zenbu-site-2.0 `AssignmentsManager.tsx` / `AssignmentsModal.tsx` 為準。

## 關鍵元素
- 章節作業列表：依排序顯示作業標題、截止時間、題型摘要（文字 / 檔案 / 必填 / 附件上限）；支援拖拉排序（`features/assignment/排序作業.feature`）
- 新增 / 編輯作業表單（`features/assignment/建立作業.feature`、`更新作業.feature`）：
  - 標題（1-200 字）
  - 作業說明（Power Editor）
  - 允許文字繳交、文字必填
  - 允許檔案繳交、檔案必填、附件數量上限（1-20）
  - 截止時間（DatePicker，可留空 = 無截止；以站台時區顯示）
  - 所屬章節（可改掛到其他章節）
- 刪除作業（移至垃圾桶，確認對話框提示「學員繳交紀錄會保留」，`features/assignment/刪除作業.feature`）
