## 行為分類與句型骨架

### Creation

**When 句型模板**：`When {角色} "{name}" {建立動詞}{對象}，參數如下：`（接 Data Table）
**Then 句型模板（成功）**：`Then 操作成功` + `And {對象} 應為：`（接 Data Table，States Verify）
**Then 句型模板（失敗）**：`Then 操作失敗，錯誤為「{錯誤訊息}」`

### Mutation

**When 句型模板**：`When {角色} "{name}" {動詞}{對象} {id}，參數如下：`（接 Data Table，無參數時省略）
**Then 句型模板（成功）**：`Then 操作成功` + `And {對象} {id} 應為：`
**Then 句型模板（失敗）**：`Then 操作失敗，錯誤為「{錯誤訊息}」`

### Query

**When 句型模板**：`When {角色} "{name}" 查詢{對象}，參數如下：`
**Then 句型模板（成功）**：`Then 操作成功` + `And 查詢結果應為：`（接 Data Table，Result Verifier）
**Then 句型模板（失敗）**：`Then 操作失敗，錯誤為「{錯誤訊息}」`

### Diagnostic

本 scope 無 Diagnostic 操作。

## 共用契約

### Postcondition 模式

- **管理員寫入類操作**成功後以 `And {實體} {id} 應為：` 驗證 DB 狀態。
- **批改副作用**（批改作業、匯入批改結果 CSV 共用）：pass → 章節自動完成；pass / fail → assignment_graded 郵件；副作用失敗不影響主操作。

### Violation 模式

| 前置條件 | 錯誤訊息 | HTTP |
|---------|---------|------|
| 非管理員呼叫管理端操作 | 權限不足 | 403 |
| 未登入呼叫學員端操作 | 必須登入 | 401 |
| 學員對作業所屬課程無有效觀看權 / 已到期 / 未開課 | 尚未報名此課程 | 403 |
| 課程啟用線性觀看且作業所屬章節對學員鎖定（僅繳交作業） | 此章節尚未解鎖，請先完成前面的章節 | 403 |
| 作業不存在或在垃圾桶 | 作業不存在 | 404 |
| 繳交紀錄不存在 | 繳交紀錄不存在 | 404 |
| 章節不存在 | 章節不存在 | 404 |
| 題型設定皆不允許 | 至少需允許文字或檔案其中一種繳交方式 | 400 |
