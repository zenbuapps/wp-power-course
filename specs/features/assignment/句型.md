# Assignment 句型模型

> 產出：`zenbu-powers:aibdd-form-bdd-analysis` Phase 2（2026-09-17）
> Boundary：web-backend（Handler 依 `references/web-backend/句型分析方針.md` 分類）
> 業務依據：zenbu-site-2.0 course-assignments（見 `specs/clarify/2026-09-17-1415-issue131-assignment-grading.md` D1–D26）

## 實體概述

- **性質**：Aggregate × 4（作業、作業繳交、作業附件、作業討論訊息）
- **攜帶狀態**：見 `specs/features/系統抽象.md` 實體清單
- **Invariant 清單**：
  - 作業：allow_text 與 allow_file 至少一個為 yes；max_files ∈ [1, 20]；menu_order ≥ 0；due_at = 0 或 10 位 timestamp
  - 作業繳交：(assignment_id, user_id) 唯一；status ∈ pending / pass / fail；重交後 feedback / graded_by / graded_at 為空
  - 作業附件：file_size ≤ 50MB；mime_type ∈ 白名單
  - 作業討論訊息：body 長度 1-10000；read_at 只由接收方讀取時寫入

## 句型清單

> 值表示法：`{字元 x N}` 表示長度為 N 的字串；`{N 個作業 id}` 表示 N 個作業 id 的陣列；Data Table 中空白格表示 null / 空字串；`[a, b]` 表示整數陣列。
> 時間：`"YYYY-MM-DD HH:MM:SS"` 一律為站台時區（Asia/Taipei）；CSV 內時間沿用參考實作 ISO 8601 UTC。

## 測試分析

### 建立作業
**等價類劃分**：最小參數（只給 chapter_id + title，套預設值）/ 完整參數；題型組合（僅文字 / 文字+檔案 / 僅檔案）。
**邊界值分析**：title 0 / 201 字；instructions 20001 字；max_files 0 / 21；menu_order -1；due_at 非 10 位。
**狀態轉移**：章節存在 / 不存在。
**組合覆蓋**：allow_text=no 且 allow_file=no（非法組合）。
**錯誤推測**：非管理員呼叫；未帶 chapter_id。

### 更新作業
**等價類劃分**：部分更新 / 改掛同課程章節 / 改掛其他課程章節。
**邊界值分析**：title ""、max_files 21、due_at 非 10 位。
**狀態轉移**：作業存在 / 不存在 / 在垃圾桶；更新後題型組合非法。
**組合覆蓋**：更新 allow_text=no 時與既有 allow_file=no 合併驗證。
**錯誤推測**：更新不應影響既有繳交狀態。
